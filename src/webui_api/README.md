# LLM Security Proxy - Web UI API Server FastAPI backend providing REST API endpoints for the React frontend. ## Architecture ``` React Frontend (port 3000) → API Server (port 8000) → LLM Security Proxy (port 8080) → LLM Providers ``` ## Running ```bash # Development python -m src.webui_api.main # Or with uvicorn directly uvicorn src.webui_api.main:app --host 0.0.0.0 --port 8000 --reload ``` ## API Documentation When running, visit: - Swagger UI: http://localhost:8000/docs - ReDoc: http://localhost:8000/redoc ## Project Structure ``` src/webui-api/ ├── __init__.py ├── main.py # FastAPI app + CORS + static files ├── routes/ │ ├── __init__.py │ ├── providers.py # Provider management endpoints │ ├── chat.py # Chat completion proxy │ └── dashboard.py # Dashboard data endpoints └── services/ ├── __init__.py ├── provider_service.py # Provider logic + model data ├── dashboard_service.py # Dashboard data aggregation ``` ## API Endpoints ### Providers - `GET /api/providers` - List all providers with status - `GET /api/providers/{id}/models` - Get models for a provider - `POST /api/providers/switch` - Switch active provider - `POST /api/providers/api-key` - Set provider API key ### Chat - `POST /v1/chat/completions` - Proxy chat completion to LLM Security Proxy ### Dashboard - `GET /api/dashboard/health` - System health status - `GET /api/dashboard/metrics` - Request metrics - `GET /api/dashboard/features` - Security features list - `GET /api/dashboard/pipeline` - Security pipeline phases - `GET /api/dashboard/issues` - Known issues by severity - `GET /api/dashboard/codebase-stats` - Codebase statistics - `GET /api/dashboard/components` - Component inventory - `GET /api/dashboard/roadmap` - Improvement roadmap ### Health - `GET /api/health` - API server health check ## CORS Allowed origins: - http://localhost:3000 (React dev server) - http://localhost:8000 (Same-origin production) ## Static Files In production, the built React app is served from `src/webui-react/build/`. All non-API routes fall through to the React SPA.
